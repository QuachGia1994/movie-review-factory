# Creator production roadmap
Status: active · 2026-09-27. Product direction: [creator product identity](../biz/creator-product.md). The existing [Clipto parity roadmap](clipto-roadmap.md) documents media search and indexing; this plan closes the creator's production loop.

**Definition of production:** a solo creator can finish a source-grounded, editable, quality-checked review from an authorized source and export its complete delivery package on a clean Windows machine. No phase is marked complete by unit tests alone. A human retains script, source-use and publication decisions. Numbers below are acceptance thresholds for this product, not market facts.

## P0 — reliable source-to-review flow
- [ ] **P0.1 Actual voice timing:** collect TTS spoken-word timing or align recorded narration acoustically; map each section/cue to measured start/end rather than whole-video word ratio. Two lines max, ≤42 visible characters per line, readable duration and safe margin. QA spot-check first/middle/end and every inserted CTA against heard voice (target ±0.5 s) on at least one real 8–12 minute video.
- [ ] **P0.2 Scene/narration sync:** derive visual section cuts from measured voice section bounds, including midroll; eliminate intentional replay/loop surprises unless manually chosen. Compare at least three source/montage transitions per section in full play-through.
- [ ] **P0.3 Editorial QA:** supplement ffprobe with decoded sample frames (black/frozen/repeated sequences, subtitles outside safe frame, legacy source watermark/text collision) and sampled loudness/peaks. Findings point to exact output/source timecodes; creator explicitly resolves severe issues. Technical codec/duration QA remains.
- [ ] **P0.4 Recoverable edits:** create named versions of script, scene plan, captions, metadata and final output; undo or restore a version; cancel/failure never corrupts last passing export. Approval resets only when its approved content changes.
- [ ] **P0.5 Real source validation:** one authorized 8–12 minute film from import through indexed story, AGY script, human approval, voice, captions, timeline, final QA and downloadable package; document every manual correction. Ben 10 midroll is now approved; complete synthesis, render, decoded QA and a creator review of the changed output.
- [ ] **P0.6 Clean Windows:** test one-file bundle on a machine without prior Node/Python/FFmpeg/models, first run and offline relaunch with cached runtime; release gate and fresh full suite green.

## P1 — creator editing and channel identity
- [ ] **P1.1 Creative brief:** project fields for review thesis, comedic/analytic tone, target audience, spoiler choice, forbidden claims and desired length; AGY uses them in outline and script. Creator can tag lines as plot recap vs original opinion; inspect names/events against transcript/scene evidence.
- [ ] **P1.2 Fast edit loop:** script and per-section player/timeline in one workspace; edit line/cue, trim/replace/lock shot, listen and preview low-resolution result without full re-render; regenerate only affected artifacts and visually compare before/after.
- [ ] **P1.3 Audio finish:** optional authorized music/SFX tracks, voice/music gain and ducking, output loudness and true-peak checks; clear mute default, no surprise source soundtrack.
- [ ] **P1.4 Reusable brand:** editable channel name/logo, tested overlay on footage; configurable CTA, chapter cards, intro/outro; one project may override channel defaults. Mark existing source watermark/text for manual review; never silently erase or claim rights. _(intro/outro cards and the `source_watermark_text_review` flag are implemented and tested; the box stays open for the creator's source-use review and real-output walkthrough.)_
- [ ] **P1.5 Packaging:** handoff bundle MP4, SRT/VTT, selected thumbnail, editable title/description/tags/chapters, credits/source-use notes, plus a manifest identifying exact approved revision and QA result. _(Builder and download path are tested; the Ben production ZIP is intentionally blocked because `youtube_metadata.json` is not creator-approved.)_
- [ ] **P1.6 Short variants:** select approved highlight of finished commentary, create coherent 9:16 clip with reframing, own caption timing and outro; no unreviewed raw-film highlight represented as original review.

## P2 — channel workflow and feedback
- [ ] **P2.1 Thumbnail/metadata editor:** layered title and artwork safe area, at least three alternatives, preview at small size; use YouTube Studio native title/thumbnail A/B experiment instead of duplicating it.
- [ ] **P2.2 Publish handoff:** clearly distinguish export-ready from uploaded, prepare YouTube upload checklist and optional draft/private upload only after explicit platform authorization; display YouTube's own copyright check result, never assert pre-upload clearance.
- [ ] **P2.3 Analytics learning loop:** creator imports or links YouTube Studio retention, CTR, impressions and title/thumbnail test results to exported revision; highlight intro/CTA drop-off and store manual learning notes. No fake predicted-virality score.
- [ ] **P2.4 Project/library operations:** batch/series planning, reusable briefs, asset rights/provenance and search across projects; tune background indexing only against measured multi-project load.
