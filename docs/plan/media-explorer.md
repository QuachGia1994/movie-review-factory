# Media Explorer checkpoint

Scope: complete the current uncommitted Clipto-inspired local-media slice on top of v0.2.0; keep user-approved script/publish gates and the one-file Windows launcher.

## Verified implementation

- Per-job SQLite/FTS5 index of source video, bounded scene ranges including silent spans, transcript, and persistent visual observations. AGY observations store a visible description plus grounded tags, person labels, and actions; Media Explorer searches and displays both transcript and visual evidence.
- Scene frame previews, WebVTT subtitles, local heuristic highlight suggestions and optional vertical clip export; transcript chat only cites indexed segments. Library Search queries visual memory and transcript indexes across projects and opens a matching project at the source timecode.
- Browser video uses HTTP byte ranges and a scoped same-site, HttpOnly stream cookie issued after bearer-authenticated API access. Jobs/status and mutation endpoints still require the bearer token.
- Re-indexing and upstream invalidation remove derived scene frames, subtitle export, and highlight clips; generated one-file JS embeds the index and migrations.
- Browser MP4 import streams to a job-owned file with upload progress and a retry path. Project and artifact lists render as cards; individual or selected batch deletion is confirmed before removing job directories and preflights the whole selection for active/missing projects. QA-passed MP4 has a direct download card.
- Scene planning is visual-index-first for Claude jobs: AGY inspects every bounded indexed scene before per-section retrieval, then retrieval ranks transcript text, visual descriptions/tags/person labels/actions, and a timeline anchor while keeping at most 12 candidates per section. This allows visually relevant silent scenes to enter the bounded Claude context. Claude selections outside supplied candidates remain rejected. Direct frame input to the configured Claude CLI remains disabled after a live unsupported-image probe. Quota failures rotate through advisor, executor, experiment, and reviewer; cached SQLite observations remain usable if a later AGY pass is unavailable, and no visual label is invented when inspection fails.
