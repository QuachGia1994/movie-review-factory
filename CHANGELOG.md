# Changelog

All notable changes to Movie Review Factory are documented here.

## [Unreleased]

### Added
- Optional single cache folder (`runtime_cache.py`): setting `MRF_CACHE_ROOT` points the Hugging Face, torch, uv, pip, Playwright, faster-whisper, embedding and ProPainter caches under that one folder (values you already set win). The one-file launcher sets it to the app-data cache (`%LOCALAPPDATA%\MovieReviewFactory\cache`), so a packaged install no longer spreads model downloads across the user profile. The whisper and embedding models move from `MovieReviewFactory\models` to `MovieReviewFactory\cache\models`, so an existing install downloads them once more on the next online launch (offline mode needs that one online run first). The Hugging Face "symlinks not supported" warning on Windows without Developer Mode is now silenced (`HF_HUB_DISABLE_SYMLINKS_WARNING=1` unless already set); caching works the same.
- YouTube packaging (`packaging.py`), modelled on top Vietnamese review channels: the metadata stage drafts a curiosity title in the shape `Review phim {thể loại} | {phim}` plus alternatives (`title_options`), a description with hook paragraph, timestamped chapters from `render.json`, series part line, `?sub_confirmation=1` subscribe link, fair-use notice and hashtags (format, film, channel first), search tags, and a pinned comment with a specific comment question and next-part tease. Claude/AGY jobs ask AGY for titles, hook, comment question and tags (`MRF_AUTO_PACKAGING=0` keeps the deterministic draft; failures fall back silently). The metadata panel edits the pinned comment and offers the title options; the handoff zip adds `pinned-comment.txt` and lists both in `upload-notes.txt`.
- Retention structure for outline/script prompts (`story_structure`): one greeting line with the channel name or the profile's own greeting, 2-3 curiosity questions plus a stay-to-the-end promise, story entry before 0:40, an open loop at the end of every section, twist kept for the end, rumours labelled as rumours, and an ending that pays off the hook, asks a specific comment question and asks for like/subscribe. Series jobs mention the previous part and tease the next one.
- Compilation mode for anthology films: `review_format: compilation` (create form "Dạng video", CLI `--review-format`) structures the video as "Câu chuyện thứ N" sections, each with its own setup, climax and bridge. Optional `genre` feeds titles, hashtags, tags and prompts.
- Genre voice (`genre_tone.py`): the job `genre` (accent-insensitive, VI/EN) selects one of 12 narration voices (horror, thriller, crime, action, comedy, romance, drama, sci-fi, fantasy, animation, war, disaster) whose tone, rhythm, vocabulary and avoid-rules join `story_structure`; it also picks a genre-specific comment question and steers AGY titles. Blends like "Kinh dị hài" lead with the first genre. The create form suggests genres.
- Genre TTS voice: the genre also picks the speaking rate, pitch and default voice (deep male NamMinh/Guy/leminh for dark genres, HoaiMy/Aria/banmai for light ones; e.g. horror -10% / -6Hz). Edge applies rate and pitch, FPT.AI gets `speed`, ElevenLabs `voice_settings.speed`. Word targets, beat planning and shot pacing scale with the rate so the target length holds. Edge now also honours an explicit Edge voice name in `tts_voice`. A job voice beats the genre voice, `MRF_TTS_EMOTION` replaces the genre prosody, `MRF_GENRE_VOICE=0` turns it off.
- Channel profiles gain `greeting` (verbal branding line) and `channel_url` (https, used for the subscribe link).
- Thumbnail variants add a bottom "Review Phim : {phim}" band (white label, yellow film title, red stripe) whenever the job names the film; headlines move up to make room and the band shrinks or truncates long titles to stay inside the safe area.
- Quick config now has a review target length ("Mục tiêu thời lượng review", 1–60 min) in Scout's "Dựng review video này" dialog, and the overnight batch gets the same quick config for the whole queue (length, watermark, content agent, clip transform, voice). Each batch item now runs in one pass to `final.mp4` (script auto-approved, render, cover) instead of stopping at the script draft; batch jobs previously defaulted to the scaffold agent.
- Brand guard: the corner logo + channel name hop between the top corners every 45 s and a faint (16 %) ghost lockup jumps to per-job pseudo-random spots every 11 s, so a static delogo/blur/inpaint mask cannot strip the brand (see `docs/research/brand-guard.md`). Jobs with a top band keep the static lockup in the band. Off switch `MRF_BRAND_GUARD=0`.
- New transparent Màn Kể logo (speech-bubble screen with curtain and play triangle, dark halo instead of a tile); `scripts/render_brand_logo.py` regenerates `assets/man-ke.png` and `man-ke.svg`.
- Auto mid-roll CTA: the script stage now has AGY write a like/subscribe line (always AGY, for Claude and AGY jobs) and inserts it as a `midroll` section near 50% of the narration, splitting a section at a sentence boundary when no boundary is close enough; the operator reviews or edits it inside the script before approval. A CTA failure never blocks the script (the stage message says `CTA skipped: ...`; the manual CTA panel still works). Off switch `MRF_AUTO_CTA=0`.
- Automatic production flow (`MRF_AUTO_RUN`, default on): importing or downloading a source runs in one pass to the finished video — AGY writes the script and places the mid-roll CTA, the script is auto-approved (it stops at the script gate only if approval fails, e.g. evidence tags need review), and the same run continues to `thumbnail` and preselects the first branded AGY cover. `MRF_SCRIPT_REVIEW=1` brings back the stop for manual script review; approving metadata builds the handoff package (the dashboard downloads the zip). `publish` still needs its explicit confirm. `MRF_AUTO_RUN=0` restores fully manual runs.
- Content Scout: 20 cards per scan (`DEFAULT_SCOUT_LIMIT`), one topic catalog (`SCOUT_TOPICS`) with 10 new trending genres (Asian horror, martial arts, crime/heist, psychological thriller, sci-fi/time loop, survival/disaster, zombie, monster, hidden identity/战神-赘婿, palace intrigue) that also generates the dashboard topic select. Each "Quét lại" rotates to the next queries (2 per source, in parallel), searches deeper after a full lap, prefers cards not shown before (history in `scout_cache_history.json`), backfills empty source slots, and once the built-in pool is exhausted asks AGY for fresh trending queries (`MRF_SCOUT_IDEAS=0` to disable). Scout cache bumped to v3.
- English narration style (`narration_style.py`): English jobs send outline/script prompts an English recap guide (hook in the first two sentences, present tense, ear-friendly TTS-safe sentences, open loops) plus per-section word targets at ~155 wpm, and get English scaffold text, YouTube metadata draft (movie-title based), thumbnail headlines and mid-roll CTA; Vietnamese prompts are unchanged. TTS now fails clearly when the Vietnamese-only FPT.AI provider is set on a non-Vietnamese job.
- Cheap watermark removal methods: `watermark_removal.method` = `propainter` (default) | `delogo` | `blur` (CLI `--watermark-method`). `delogo`/`blur` run FFmpeg on one static mask in minutes on any CPU (a 10-min 1080p source: ~2.5 min, versus tens of hours for CPU ProPainter). A per-frame mask folder is reduced to `watermark_mask_static.png` keeping only pixels marked in >=5% of frames, so one-frame detector noise no longer floods the mask (a real color-detector run: 77% -> 1.2% coverage); `watermark.json` records `method` and `mask_coverage`. Docs add a method comparison and the letterboxed-source recipe (brand bands + one delogo box).
- Pinned, checksum-verified ProPainter installer (`propainter_setup.py`) with traversal-safe archive extraction and a readiness check (marker, models, interpreter).
- Content Scout (`content_scout.py`, `GET /api/scout/discover`, `POST /api/scout/enqueue`): discovers hidden-gem films and short dramas from YouTube (yt-dlp flat search) and Bilibili, filters by duration (films 45–120 min, dramas 30–60 min), ranks by a viral score (story-twist concepts x rating / popularity x copyright risk), checks link liveness (oEmbed/HTTP, soft-404), caches results (`ScoutCache`, `&refresh=1` bypass), and turns a candidate into a project through a config dialog with a one-click YouTube fallback search; adds `httpx` as a core dependency.
- Multi-channel profiles: save several channel identities (name, logo) with job-creation defaults (language, aspect, TTS, intro/outro, brand bands, copyright profile), switch the active channel, and prefill new jobs from it without mutating existing ones. Per-channel transition SFX (up to 8, rights note required) can be inserted at a timestamp or auto-placed at rendered scene cuts (16-effect cap; re-running replaces the auto set).
- VieNeu-TTS provider: free offline Vietnamese voice (24 kHz, no API key), run in an isolated Python 3.12 environment on Windows/Python 3.14+; a whitelisted 1-click installer (`POST /api/system/install-package`) sets up VieNeu, Edge-TTS or ProPainter from the dashboard.
- Project settings stay editable after creation (`POST /api/jobs/{id}/config`: title, content agent, copyright profile, watermark removal incl. method, TTS, target length, aspect; refused while the pipeline runs), and the create/scout/edit forms offer the watermark method with Vietnamese tradeoff help.
- Auto thumbnails (`POST /api/jobs/{id}/thumbnails/auto`): AGY-written headlines, a distinct headline per variant, always covering a source's residual band watermark.
- TTS connection check in the dashboard ("Kiểm tra kết nối"): a Settings button and `GET /api/tts/test` validate the active provider's API key without spending synthesis credits — ElevenLabs reports remaining character quota via `/v1/user/subscription`, FPT.AI confirms key presence (no free balance endpoint), Edge-TTS needs none (`tts_providers.check_provider`, injectable HTTP for offline tests).
- Offline, machine-bound licensing (`licensing.py`): `mrf serve` is gated by an Ed25519-signed, machine-fingerprinted license verified fully offline — an unlicensed machine shows an activation screen and mutating APIs return 402 until a valid key is entered (stored at `%LOCALAPPDATA%\MovieReviewFactory\license.key`, or supplied via `MRF_LICENSE`). The shipped app embeds only the public key; licenses are issued by the vendor-only `tools/issue_license.py` (not shipped in the installer). Adds `cryptography` as a core dependency, bundles the module in the one-file build, and documents the flow in `docs/licensing.md`.
- Read-only YouTube Studio retention advisory (`analytics.retention_advice`): averages recent measured `intro_drop`/`cta_drop`/`ctr_percent` and surfaces suggestions (tighten the hook, move the CTA, lift thumbnail CTR) into the creative-brief and hook-crafter flow and the dashboard analytics panel — strictly advisory, never auto-mutating the script (off switch `MRF_RETENTION_ADVICE=0`; a low-confidence flag under 3 samples). Adds a 4-step "lấy CSV từ YouTube Studio" guide modal.
- Pluggable studio-grade TTS providers (`tts_providers.py`): optional FPT.AI Voice and ElevenLabs alongside the default offline Edge-TTS, selectable per project (`tts_provider`/`tts_voice`, or `MRF_TTS_PROVIDER`/`MRF_TTS_VOICE`) with a dashboard picker and sample voices; provider API keys are read from env only (`MRF_FPTAI_API_KEY`/`MRF_ELEVENLABS_API_KEY`) and never persisted. Non-edge providers estimate word timing from the probed chunk duration; `voice.json` and the dashboard record the active engine/voice.
- Windows 1-click desktop installer (`scripts/package_windows.py` + `installer/movie-review-factory.iss`): stages embedded Python 3.12 + FFmpeg/ffprobe + yt-dlp + the app and builds a per-user Setup whose Desktop/Start shortcut starts the local server and opens `http://localhost:8765`; adds a `python -m movie_review_factory` entry point and build + code-signing/SmartScreen docs (`docs/windows-installer.md`).
- Overnight Batch Factory queue (`batch_queue.py` + dashboard "Hàng đợi hàng loạt"): paste many links to run sequentially to the script-review gate (approval gate intact — never auto-approved), fault-tolerant so one bad link is logged and skipped; an optional completion webhook pings Discord/Telegram (`MRF_DISCORD_WEBHOOK_URL`, or `MRF_TELEGRAM_BOT_TOKEN` + `MRF_TELEGRAM_CHAT_ID`).
- Download-from-link ingest via yt-dlp, gated on an explicit usage-rights confirmation (`link_download.py`): fetches <=1080p mp4 + matching vi/en subtitles into a project as `source.mp4`, exposes a dashboard "Kiểm tra link" metadata probe, and ships no IP-block/cookie/proxy evasion tooling by design.
- Per-clip visual variety (`visual_variety.py`): horizontal flip, subtle zoom-crop and colour grade applied in the render via `off`/`light`/`balanced`/`aggressive` profiles (`cfg.visual_variety` / `MRF_VISUAL_VARIETY`); manifests, channel profiles and the env var saved under the earlier `copyright_bypass` name still load.
- Hook teaser (`hook_crafter.py`): deterministic bilingual (EN/VI) most-dramatic-scene selection from `scenes.json` cuts a standalone 3-5s `hook.mp4` (+`hook.json`) with a punch-in zoom and optional impact SFX (`MRF_HOOK_SFX`); it never reads or modifies `final.mp4`.
- Full-frame watermark removal stage (`watermark_removal.py` + `mask_detection.py`): optional ProPainter-based reconstruction driven by a configured mask/band/box or color/temporal/external detectors, writing `source_clean.mp4` upstream of the render.
- Word-level transcript timing (migration `007_transcript_words.sql`): the transcript stage records per-word start/end and splits coarse VAD segments on sentence ends and silent gaps, so caption cues anchor to real speech instead of drifting by character-count interpolation.
- Visual rhythm helpers (`visual_rhythm.py`): optional Ken Burns motion (`MRF_KEN_BURNS`) and per-cut transition SFX (`MRF_TRANSITION_SFX`) in the render.
- Recorded creator product identity and a production roadmap for measured narration timing, editorial QA, recoverable edits, channel branding, delivery package, audience feedback and clean-Windows release checks.
- The creator dashboard now includes a reusable creative brief, exact-span recap/opinion tags with internal source references, named edit versions and conservative restore, decoded black/freeze/silence and loudness QA, optional rights-tracked voice/music/SFX mix, and approved-commentary 9:16 short export. Local series/brief/asset-rights planning and measured Studio analytics import modules are available; their dashboard integration and creator walkthrough remain in progress.
- Spoken-word TTS timing now drives two-line subtitle cues and measured section cuts in the renderer; QA checks caption geometry, source provenance, repeated or stretched footage, and voice/visual section drift, and actual midroll placement within the central 40–60% of narration. Ambiguous spoken-word chapter matches fail QA. The AGY midroll remains behind script approval.

### Changed
- Picture now keeps up with the narration: any shot longer than ~3 s of speech becomes a montage that keeps its matched scene first and then walks forward through the film (unused scenes between it and the next matched scene, or a compression-sized stretch after it), instead of one scene playing in real time while the recap races ahead. Applies to AGY beat mode and section mode (Claude); `MRF_SHOT_SECONDS` (1.5–12, default 3) sets the pace and `scene_plan.json` records `pacing`. The render times each narration beat to its first spoken word from the TTS word boundaries (`render.json` `visual_timing_mode: voice_beat_words`), falling back to section bounds. Vietnamese script prompts now carry three sync rules (film order with one on-screen moment per sentence, ≤~25 syllables per sentence, at most two commentary sentences in a row). Existing jobs pick it up by re-running from `scene_plan`. Rationale: `docs/research/picture-sync.md`.
- Render overlay no longer draws dark plates behind the logo, channel name or chapter caption outside opt-in bands; text uses a stroke and soft halo so footage stays visible.
- Scene plan for AGY jobs with frame descriptions is now beat-level (`shot_planner.py`): each narration section is split into ~4 s spoken beats, AGY first locates every beat on a compact whole-film timeline of frame descriptions, then picks one scene per beat inside those windows (sections in parallel, reused scenes moved to a free neighbour). Picture now follows each sentence instead of 3 evenly split shots per section chosen near the section's proportional film position. `scene_plan.json` records `shot_mode` (`beat`/`section`) and `shot_error`; the old section planner remains the fallback.
- Render splits each section's voice time by beat length (clip `weight`) and reads the middle of a source range longer than its slot instead of only its first seconds.
- Script length: Vietnamese prompts now get per-section word targets (240 syllables/min, measured on VieNeu/FPT output; no style guide), and sections below 85% of target are rewritten toward it in up to two parallel `script_expand` passes. `script.json` records `word_count`/`target_words`. A 10-minute Vietnamese job previously came out at 3.5-6 minutes.
- AGY pool runs in parallel on all configured accounts: scene describe, identity tracking (one batch per account per wave, each with its own fresh `Person N` range), story graph and Scout live localization no longer wait on one account at a time. Vision batches grow from 6 to 12 scenes, and the story graph is split into ~18,000-char chunks so long films (hundreds of scenes) no longer exceed the AGY prompt limit. Vision resume keys now include the batch/chunk sizes, so an in-progress scene_plan redoes its vision steps once after upgrading.
- Dashboard "Noir & champagne" reskin: black + champagne-gold tokens (light theme keeps a darker gold for AA contrast), self-hosted Cormorant/Montserrat woff2 with Vietnamese subsets (`/assets/fonts/*`, public, ~95KB, OFL), SVG brand/theme icons, the license activation page restyled to match, a thin busy bar after 300ms of pending API calls and loading shimmer that stops when idle (off under `prefers-reduced-motion`). The one-file launcher opens Edge/Chrome as an `--app` window (own profile under the app data root); `--browser-tab` or a missing browser falls back to the default browser. See `docs/plan/noir-champagne-reskin.md`.
- ElevenLabs/FPT.AI requests retry 429/503/timeouts with backoff (honoring `Retry-After`) and fail fast on 401.
- The local server refuses a non-loopback bind without `DASHBOARD_TOKEN`, bounds request time (15s) and concurrent handlers (32), and stops its background workers on shutdown.
- The dashboard now shows the next action after import, draft script, render, or QA; script and metadata fields reload when pipeline artifacts first appear.
- Thumbnail generation now honors the job aspect ratio (1280x720 for 16:9, 720x1280 for 9:16).
- Claude content-agent invocation passes tools through a single `--tools` flag (empty for non-research stages) instead of the removed `--allowed-tools` duplicate.
- Source and final video previews stream with HTTP ranges and scoped media-session authorization; the token-protected dashboard shell opens before the fragment token is read, and malformed byte ranges are rejected before streaming. Media cache is cleared when its source index changes. Dialogue retrieval now ranks real words and returns no citation when no transcript matches.
- Claude scene retrieval is now visual-index-first and semantic-aware: AGY inspects all bounded scenes, anonymous `Person N` continuity and story-memory links are built before embedding refresh, and scorer v2 reranks the full bounded scene set while keeping the 12-candidate context limit. Cached observations/tracks/story graph provide a grounded fallback when a later AGY pass is unavailable.
- One-file packaging discovers numbered SQL migrations automatically instead of hard-coding a single migration; the full managed runtime now includes FastEmbed and an app-owned embedding-model cache with offline reuse.
- Semantic search scores with exact numpy matrix math (chunked, pure-Python fallback when numpy is absent): `search_store` p95 on the real job index drops from ~128ms to ~1.2ms at 383 vectors with unchanged ranking, tie-breaks, and `-1.0` dim-mismatch/zero-norm parity.
- AGY pool scheduler v2 (`pool_scheduler.py`): bounded retries with backoff (`MRF_AGY_RETRIES`, 0-3), a 300s role cooldown (`MRF_AGY_COOLDOWN_SECONDS`) that skips only the cooled-down role, partial resume via `ScheduleResult`, and per-role quota/health telemetry (status, latency_ms, cooldown_until) written to `%LOCALAPPDATA%\MovieReviewFactory\runtime\pool_health.json`. AGY prompts fit the measured ~26,000-char backend limit (`MRF_AGY_PROMPT_MAX`) with tiered scene/candidate context instead of failing the request.
- Ignore local scratch/dev artifacts (`_*_tmp.py`, dashboard logs, clipboard images, scratch reports) via `.gitignore` so they never enter a release.

### Removed
- Removed the unwired micro-speed bypass knob (`speed_factor` / `speed_filter`): clip video is concatenated silent while the independent TTS narration is the fixed-length master audio, so a video-only tempo shift would desync the two - it is intentionally not applied.

### Fixed
- Bilibili link downloads no longer stall on Akamai mirrors: metadata is dumped first, stream URLs on `upos-*-mirrorakam.akamaized.net` (including nested `requested_downloads`) are moved to Bilibili's own `upos-sz-mirrorcos.bilivideo.com` mirror and downloaded with `--load-info-json`; downloads prefer AVC, retry once at 720p on stream failures (`stream_warning`), and yt-dlp errors starting with a progress redraw are reported correctly.
- AGY vision no longer aborts a whole parallel run on one slow or malformed answer: timeouts and unusable output retry the batch on another account (HTTP rejections and quota keep their existing paths), the per-call timeout is 240 s for 12-frame batches, and the story graph drops untracked/real-name people (and their relations) instead of failing the entire graph.
- "Mở phần duyệt" / "Duyệt & xuất" showed an empty page: the reskin dropped the closing tag of `#view-explore`, so the review, edit and files views were nested inside the hidden explore view. A test now checks that workspace views are siblings.
- Content Scout cards for live YouTube/Bilibili finds now read like the curated ones: one AGY call per scan batch (`localize_live_candidates`, cached with the scan; off with `MRF_SCOUT_LOCALIZE=0`) writes a Vietnamese title with year and a short Vietnamese plot summary, instead of an identical generic label such as "Phim xưa độc lạ: Câu Chuyện Bí Ẩn". If AGY fails, the card falls back to the real upload title (minus "| Full Movie | cast" noise) and the original description. "Dựng review phim này" prefills the shown title.
- Scene plan no longer fails with "scene index belongs to a different source video" when watermark removal is on: the index built from `source_clean.mp4` is accepted alongside the configured source.
- Video preview no longer logs a server traceback when the browser stops reading a stream (paused buffer, seek): a socket write timeout is treated like a closed connection instead of falling through to a 500 reply on the dead socket.
- A successful render deletes `final.pre-midroll.mp4`: the pre-CTA copy was never re-rendered, so it kept old captions (e.g. mid-screen subtitles) after later fixes. Script and scene-plan backups are kept.
- Rendered audio is loudness-normalized to YouTube's -14 LUFS (true peak -1.5 dB) instead of shipping at about -20.6 LUFS.
- Clips shorter than their narration slot now extend into adjacent footage no other clip uses (forward, then backward) and loop only the remaining shortfall; `render.json` records the extended `read_start_seconds`/`read_seconds` and the stretched-footage QA check uses them.
- VieNeu is allowed for English jobs (v3 Turbo is trained on English-Vietnamese speech); only FPT.AI is rejected for non-Vietnamese narration.
- Download-from-link no longer fails with "yt-dlp is not installed" on the one-file runtime: the launcher now installs `yt-dlp` and `httpx` with the core dependencies (httpx is import-checked) and hands its `uv` to the server (`MRF_UV`); on first use the app self-installs yt-dlp via pip or, when the uv-made venv has no pip, via `uv pip install`, and a remaining failure reports why. Scout live discovery uses the same self-install. `yt-dlp` is now a core package dependency.
- Watermark color/temporal detection now streams decoded FFmpeg frames instead of materializing full-resolution PNG scratch frames, preventing multi-gigabyte disk spikes; partial masks and legacy extraction frames are removed on failure, and temporal detection stays bounded in memory.
- yt-dlp metadata/download now run under bounded timeouts (metadata 60s; download `MRF_DOWNLOAD_TIMEOUT`, default 1800s, `0` disables) plus a 30s per-socket read timeout on downloads, so a stalled connection or livestream can no longer hang the download thread indefinitely.
- The dashboard link-download form now sends the actual rights-confirmation checkbox value instead of a hardcoded `true`, keeping the client consent gate authoritative.
- The dashboard server forces UTF-8 on stdout/stderr so Vietnamese output can no longer crash a legacy Windows console (cp1258 `UnicodeEncodeError`).
- Long Edge TTS scripts synthesize in short, retryable chunks with measured per-chunk word offsets, FFmpeg concatenation and atomic output replacement; a failed chunk cannot replace the previous narration or its approved export.
- The transcript stage now skips with `source video has no audio track - nothing to transcribe` when the source container has no audio stream, instead of failing inside faster-whisper/PyAV with `tuple index out of range`.
- Claude content-agent failures surface a bounded `head…tail` diagnostic (≤400 chars, no full stdout flood) and transient HTTP 429/5xx advisor errors are retried with `5×(attempt+1)` backoff instead of failing the stage on the first hiccup.
- QA source provenance compares against the video the render actually read (`source_clean.mp4` after watermark removal) and normalizes job-relative vs absolute paths, so a CLI run with watermark removal no longer fails with "The rendered source differs from the job source".
- `mrf` CLI output is forced to UTF-8 so Vietnamese text prints on Windows cp1252 pipes.
- Link download no longer fails when YouTube rejects the subtitle fetch (`HTTP Error 429` on `vi`/`en` subs): the video is retried without subtitles (the transcript stage falls back to Whisper) and the result carries `subtitle_warning`; failure messages show only yt-dlp's `ERROR:` lines instead of the JS-runtime/impersonation warnings.
- Media subprocesses are bounded: ffprobe (45s) and short FFmpeg calls (240s) in ingest, audio extraction, subtitle probing, duration probe, QA and chunked-TTS concat time out with the command in the error and remove partial outputs.
- Job SQLite indexes open with a busy timeout, WAL journaling and a `quick_check` that refuses a corrupt database; license keys are written atomically (temp file + fsync + replace).
- Windows packaging downloads are checksum-verified, reject a corrupt cache and extract ZIPs without path traversal; the release gate's artifact mode tests only the designated packaged runtime and never falls back to source; the one-file launcher installs and checks Pillow + cryptography as core dependencies.

### Security
- Hardened the yt-dlp invocation against argument injection: URLs are validated as http(s)-only and a `--` end-of-options guard is placed before the URL, so a value like `--exec=...` can no longer be parsed as a yt-dlp option.
